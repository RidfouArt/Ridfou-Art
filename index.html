Placement automatique

Les positions X/Y des œuvres se mesurent depuis le bord gauche du mur et le sol. Tu peux les corriger manuellement.

La photo reste sur ton appareil. Vérifie et reporte les cotes dans les champs ci-dessous : aucune mesure manuscrite n'est devinée.

2. Plan coté

En mode perçage : la première distance part du bord du mur, puis les cotes relient directement les points successifs. Les hauteurs sont indiquées depuis le sol. Touche un point sur le plan pour sélectionner son œuvre.

3. Œuvres, attaches et séries

Définis ton ordre d'accrochage en déplaçant les œuvres dans la liste. Pour une série, ajoute les œuvres une par une, avec leurs espacements et leurs positions. Les deux œuvres centrales peuvent être placées avant celles du haut et du bas.

V3 de test • Les calculs supposent que la position renseignée pour chaque attache est bien celle du point de perçage effectif. Vérifie toujours le matériel, le support et les cotes sur place avant de percer. Fonctionne hors connexion après installation et première ouverture en ligne.
